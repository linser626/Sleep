# 好眠 — 健康睡眠助手 需求文档

> 版本：v1.0 | 日期：2026-05-18

---

## 一、项目概述

### 1.1 产品定位

「好眠」是一款面向睡眠障碍人群及关注健康睡眠用户的一站式睡眠管理 APP。产品以温柔、宁静的视觉风格为核心基调，通过**睡眠打卡激励体系、助眠内容库、社区互动、外设数据监测**四大模块，帮助用户建立健康睡眠习惯、改善睡眠质量。

### 1.2 目标用户

| 用户画像 | 核心诉求 |
|---------|---------|
| 睡眠障碍人群 | 获得科学助眠方法，追踪睡眠改善进度 |
| 作息不规律者 | 建立规律作息，打卡监督自己 |
| 健康生活爱好者 | 记录睡眠数据，与同好交流 |
| 智能穿戴用户 | 对接手环数据，获得精准睡眠报告 |

### 1.3 产品目标

- 帮助用户养成规律作息习惯（核心指标：7日连续打卡率 ≥ 40%）
- 提供有效的助眠内容（核心指标：助眠内容使用后入睡时间缩短 ≥ 15%）
- 构建活跃的睡眠社区（核心指标：DAU 社区参与率 ≥ 25%）
- 实现外设数据互通（核心指标：手环绑定用户占比 ≥ 15%）

## 二、功能需求

### 2.1 模块一：睡眠打卡与激励体系

#### 2.1.1 睡眠打卡

| 功能项 | 描述 |
|-------|------|
| 每日打卡 | 用户点击"我要睡觉"按钮开始打卡，记录入睡时间；次日点击"我醒了"结束打卡，记录起床时间 |
| 自动计算 | 自动计算睡眠时长，与目标时长对比给出评价 |
| 打卡日历 | 月历视图展示打卡记录，已打卡日期显示特殊标记（如月亮图标），未打卡为空 |
| 补卡机制 | 允许用户在次日12:00前补录前一晚的睡眠时间（每月限3次） |
| 睡眠目标 | 用户可设置每日目标睡眠时长（默认8小时），系统据此评估达标情况 |

#### 2.1.2 连续打卡奖励

| 功能项 | 描述 |
|-------|------|
| 连续天数统计 | 实时显示当前连续打卡天数，断签后归零重新计算 |
| 里程碑奖励 | 连续打卡达到特定天数时获得奖励徽章和虚拟奖励 |
| 里程碑设定 | 3天（初眠者）、7天（规律者）、14天（习惯者）、30天（达人）、60天（专家）、100天（睡神）、365天（传说） |
| 虚拟奖励 | 打卡获得"星月币"，可在商城兑换助眠内容解锁、头像框、称号等 |
| 奖励通知 | 达成里程碑时推送通知，展示获得的徽章和奖励 |

#### 2.1.3 等级体系

| 功能项 | 描述 |
|-------|------|
| 经验值获取 | 每次打卡获得基础经验值，达标睡眠获得额外经验值，连续打卡有加成系数 |
| 等级划分 | Lv.1~Lv.50，每级所需经验值递增 |
| 等级特权 | 不同等级解锁不同功能：专属头像框、社区特权、助眠内容优先体验等 |
| 等级展示 | 个人主页展示等级徽章，社区发帖显示等级标识 |

#### 2.1.4 睡眠报告

| 功能项 | 描述 |
|-------|------|
| 日报告 | 每日展示：入睡时间、起床时间、睡眠时长、达标状态、评分 |
| 周报告 | 汇总一周数据：平均睡眠时长、达标天数、趋势图、改善建议 |
| 月报告 | 月度深度分析：睡眠规律性评分、最佳/最差日、对比上月变化 |

### 2.2 模块二：助眠内容库

#### 2.2.1 助眠音乐

| 功能项 | 描述 |
|-------|------|
| 音乐分类 | 白噪音、自然声、轻音乐、冥想引导、ASMR、脑波音乐 |
| 播放器 | 支持播放/暂停、进度条、音量调节、定时关闭（15/30/45/60分钟） |
| 混音功能 | 支持同时播放2-3种音效并分别调节音量（如雨声+轻音乐） |
| 收藏功能 | 用户可收藏喜欢的音乐，快速访问 |
| 智能推荐 | 根据用户历史偏好和当前时间推荐适合的助眠音乐 |
| 后台播放 | 支持APP退至后台继续播放，锁屏显示播放控制 |

#### 2.2.2 助眠视频

| 功能项 | 描述 |
|-------|------|
| 视频分类 | 冥想引导、呼吸练习、睡前瑜伽、睡前故事、自然风景、睡前放松 |
| 视频播放 | 支持横竖屏切换、画质选择、倍速播放（0.5x-1.0x） |
| 定时关闭 | 支持设定播放时长后自动停止 |
| 收藏功能 | 用户可收藏喜欢的视频 |
| 离线缓存 | VIP用户可下载视频离线观看 |

#### 2.2.3 内容管理

| 功能项 | 描述 |
|-------|------|
| 内容标签 | 每个内容带有标签（如"入睡困难"、"早醒"、"焦虑"），方便用户筛选 |
| 搜索功能 | 支持关键词搜索助眠内容 |
| 排行榜 | 热门内容排行、新上线内容、编辑推荐 |
| 内容详情页 | 展示内容介绍、适用场景、用户评分、使用人数 |

### 2.4 模块四：外设连接与睡眠监测

#### 2.4.1 设备连接

| 功能项 | 描述 |
|-------|------|
| 蓝牙连接 | 通过BLE蓝牙与手环/手表等穿戴设备配对连接 |
| 支持品牌 | 首期支持：小米手环、华为手环；二期扩展更多品牌 |
| 连接状态 | 实时显示设备连接状态，断连时提醒用户 |
| 数据同步 | 自动同步设备睡眠数据，支持手动触发同步 |

#### 2.4.2 睡眠监测数据

| 功能项 | 描述 |
|-------|------|
| 睡眠阶段 | 展示深睡、浅睡、REM、清醒各阶段时长和占比 |
| 睡眠曲线 | 可视化展示整夜睡眠阶段变化曲线 |
| 入睡/醒来 | 记录实际入睡时间和醒来时间 |
| 睡眠评分 | 基于多维数据给出0-100分综合评分 |
| 异常提醒 | 检测到异常睡眠模式（如频繁清醒、深睡过少）时给出提醒 |

#### 2.4.3 数据融合

| 功能项 | 描述 |
|-------|------|
| 手动+自动 | 手动打卡数据与设备监测数据融合，优先采用设备数据 |
| 数据源标注 | 报告中标注数据来源（手动录入/设备同步） |
| 历史对比 | 支持查看不同时期的睡眠数据对比 |

## 三、非功能需求

### 3.1 视觉风格

| 维度 | 要求 |
|------|------|
| 主色调 | 深蓝/靛蓝（#1A1A3E）为底色，搭配柔和月光黄（#F5E6A3）点缀 |
| 辅助色 | 淡紫（#9B8EC4）、星空白（#E8E4F0） |
| 字体 | 圆体/柔和字体，标题加粗，正文轻盈 |
| 图标 | 线性图标风格，月亮、星星、云朵等元素 |
| 动效 | 页面切换柔和过渡，按钮点击涟漪效果，打卡成功撒花/星星动效 |
| 整体氛围 | 宁静、温暖、治愈，避免刺激性色彩和剧烈动效 |

### 3.2 性能要求

| 指标 | 要求 |
|------|------|
| 启动时间 | 冷启动 ≤ 3秒，热启动 ≤ 1秒 |
| 页面加载 | 首屏渲染 ≤ 2秒 |
| 音视频播放 | 起播时间 ≤ 2秒，播放过程无卡顿 |
| 蓝牙连接 | 设备搜索 ≤ 5秒，数据同步 ≤ 10秒 |
| 并发支持 | 后端支持10万日活用户并发 |

### 3.3 安全与隐私

| 要求 | 描述 |
|------|------|
| 数据加密 | 用户睡眠数据传输和存储加密（AES-256） |
| 隐私保护 | 睡眠数据默认仅自己可见，社区发帖不暴露详细睡眠数据 |
| 账号安全 | 支持手机号+验证码登录，支持第三方登录（微信/Apple ID） |
| 合规要求 | 遵循《个人信息保护法》，提供数据导出和注销功能 |

### 3.4 兼容性

| 平台 | 要求 |
|------|------|
| iOS | 支持 iOS 14.0 及以上 |
| Android | 支持 Android 8.0 及以上 |
| 屏幕适配 | 适配4.7寸~6.7寸手机屏幕，支持深色模式 |

## 五、用户核心流程

### 5.1 睡眠打卡流程

```
用户点击"我要睡觉" → 记录入睡时间 → 播放助眠内容（可选）
→ 用户入睡 → 次日醒来点击"我醒了" → 记录起床时间
→ 计算睡眠时长 → 判断是否达标 → 更新连续天数
→ 发放经验值和星月币 → 检查里程碑 → 展示日报告
```

### 5.2 助眠内容使用流程

```
进入助眠页 → 浏览/搜索内容 → 选择内容 → 开始播放
→ 设置定时关闭（可选）→ 调节音量/混音 → 入睡
→ 定时结束自动停止 → 记录使用时长
```

### 5.3 社区互动流程

```
进入社区 → 浏览动态/圈子 → 查看帖子 → 点赞/评论/收藏
→ 或发帖 → 选择圈子/添加标签 → 发布 → 等待审核 → 展示
```

### 5.4 设备连接流程

```
进入设备管理 → 开启蓝牙 → 搜索设备 → 选择设备 → 配对连接
→ 授权数据同步 → 连接成功 → 自动同步睡眠数据
→ 查看设备监测报告
```
